# Page Analizer
Page Analyzer — это веб-приложение на основе Javalin, которое проверяет базовые элементы страницы, важные для внутренней SEO-оптимизации.

### Как это работает?

1. Добавьте URL-адрес, который необходимо проверить.

![Screenshot from 2024-09-20 18-09-50](https://github.com/user-attachments/assets/7e44b6ab-4445-4902-9b6b-db46dd39f063)
2. Теперь вы можете увидеть его в списке адресов. Перейдите по ссылке добавленного адреса, чтобы начать проверку.

![Screenshot from 2024-09-20 18-09-50](https://github.com/user-attachments/assets/04667fb2-d8fe-48a8-bef5-c6c701672d4c)
3. Нажмите кнопку «Проверить».

![Screenshot from 2024-09-20 18-10-07](https://github.com/user-attachments/assets/4f69861e-e5bd-4262-a4e3-870470e8f9c5)

4. Посмотрите результаты проверки.

![Screenshot from 2024-09-20 18-10-27](https://github.com/user-attachments/assets/292d3d61-acb7-45d9-b924-358aff20d72f)

5. В списке адресов отобразится краткая сводка по результатам проверки.

![Screenshot from 2024-09-20 18-10-53](https://github.com/user-attachments/assets/03f4119c-b004-49f4-a309-b2997a7dfd93)

### Установка и сборка
```
make install
make build
```
### Запуск
```
make run
```
